---
title: "Connecting MCP Servers"
description: "Configure MCP servers for HiveDeck runs."
---

Use **Settings → MCP → HiveDeck MCP** to add HTTP or stdio servers. Every entry applies to all supported CLIs in HiveDeck runs, subject to its role and board scope. HiveDeck does not change your CLI configuration files.

Choose a preset or enter a server definition, select its roles and optional boards, and save. Store header and environment secrets in the form; HiveDeck passes them to runs through environment variables.

To reuse existing definitions, open **Lấy từ config CLI có sẵn**, choose a source, and import the servers you need. Existing names are skipped. The source configuration remains unchanged.

For connecting external MCP clients to HiveDeck, see the [HiveDeck MCP Server](/integrations/hivedeck-mcp-server) guide.
